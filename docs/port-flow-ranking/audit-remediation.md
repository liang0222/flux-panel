| R-02 | 移除通配跨域配置，HTTP API 和 WebSocket 使用同一精确 Origin 策略。保留同源、Android 内置来源、明确配置的 Web 来源以及无 Origin 的节点连接 | 实际 TLS 反代和 iOS 设备 Origin 待验。iOS 需要时才显式启用 `null` |

| R-06 | Android 禁用应用备份。iOS WebView 使用非持久数据存储，会话存入仅本机可用的 Keychain 项 | 系统备份、设备迁移和恢复行为待真机验证 |
